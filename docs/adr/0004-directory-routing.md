# 分流路径由连线保存

「目录树输入」的线从实际文件或文件夹行发出，工作流用节点与来源相对路径标识这条线。和单独保存可点击创建的端口清单相比，打开工作流时可以只根据已存连线恢复路由，也能按需加载目录内容。

收起目录树后，已连接的路径仍可操作。根目录可从上游「文件输入」取得，也可在分流节点中直接选择。切换实际来源根目录会解除逐项连线，避免同一个相对路径在新根目录下自动指向另一份素材。旧工作流中的连线保持可读。

「目录树输出」以直接相连的「文件输出」为实际目录树根。现有目录端口使用相对路径，目标根变化时断开相应连线，执行前重新检查目录。规划目录端口使用独立于名称的标识，目录改名时可以保留连线，也支持同一个规划被分发到多个输出位置。
