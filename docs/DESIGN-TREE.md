### 主操作节点

复制、转码、移动、同步各自作为独立的主节点。复制策略和校验策略为具体操作提供设置。以下为后续端口与执行设计的起点。

| 主节点 | 输入 | 成功后的输出或结果 |
| --- | --- | --- |
| 复制 | 输入文件、复制策略、可选校验策略 | 写入目标的副本 |
| 转码 | 输入文件、转码设置 | 转码成品 |
| 移动 | 输入文件、目标位置 | 移动后新位置的文件 |
| 同步 | 源端、目标端、方向和同步规则 | 同步结果。向后续节点提供的文件范围待定 |

现版复制通过直接连接「目标目录」确定写入位置。实现串联时，每个写入步骤需要明确自己的输出位置。可先复制到原片目录，再把写入成功且通过已配置校验的文件交给转码，转码成品写到另一个目录。目录配置方式、文件执行粒度、移动完成条件、同步的删除和冲突规则留待设计。

## 教学与通用工作流候选

所有案例均规划为普通工作流；不引入模板对象或新的保存入口。

| 案例 | 学习目标／实际用途 | 提供时需要说明 |
| --- | --- | --- |
| 单来源单目标复制并校验 | 学会来源、目标、复制策略和 SHA-256 连接 | 首次选择自己的目录，先预览再入队 |
| 单来源双目标备份 | 一次任务写到两处并逐份校验 | 每目标分别展示结果，失败不可被整体成功掩盖 |
| 按扩展名分类归档 | 用保留/排除规则分配照片、视频等 | 未匹配内容是否保留必须明确；首例使用通用文件，不宣称可安全拆分相机卡素材 |
| 按来源目录分配目标目录 | 逐行端口到目标文件夹的连接 | 预览展示最终相对路径，解释子目录保留规则 |
| 合并来源并排除指定文件 | 区分清单合并与清单相减 | 排除不删除原文件；合并不合并文件内容 |
| 比较复制策略与校验时机 | 理解缓冲参数与两种校验时机 | 吞吐受设备影响；“复制完”不等于“校验通过” |
| Sony 整卡双目标复制 | 专业场景，保留结构与关联文件 | 当前机型识别限制、未知内容保留，不能作为通用例子的前置门槛 |

候选分批：先单目标和双目标，再目录分配与筛选，最后组合策略和 Sony 专业案例。案例不内置开发者磁盘路径；来源、目标应由用户选择。是否附演示样本、图文承载位置、是否首次启动展示等仍待讨论。

## 复核补充：需要优先向用户解释的现有差异

- 目标目录树连接实际目标目录与规划目录时，当前相对路径处理有差异：来源树选中 `DCIM/100`，接实际 `照片` 目录可能得到 `照片/100/a.jpg`，接规划 `照片` 目录则得到 `照片/DCIM/100/a.jpg`。目标目录名称相近却可能产生不同层级，必须在节点说明及预览中讲清；是否统一行为留给用户决定。
- Sony 的分类端口可显式分流，已支持同 M4ROOT 内按名称配对的片段 XML、缩略图和原片。其他素材包依赖仍待验证。Sony 前后继续限制非空扩展名筛选和清单相减，包括“只保留匹配项”。
- 相减按来源路径排除：同一来源在主清单安排了多个目标相对路径时，均会被排除。合并则按来源与目标相对路径的组合去重，两者不能简单理解为相反操作。
